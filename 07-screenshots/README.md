## Publication Rules

- Remove credentials, tokens, session cookies and API keys.
- Redact personal information and unnecessary host or network identifiers.
- Do not publish household-network scans or third-party data.
- Use authorised lab systems and state the scope in the related write-up.
- Check that filenames and links match the written evidence.
- Prefer cropped, readable screenshots showing only what supports the finding.
